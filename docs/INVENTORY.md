## 去重与身份

初次按结构化清单导入得到125条基础记录，合并30次重复出现（见 `import-log.json`）；随后加入明确的文字清单与代表性原文，第一版187条。随后回查原文、删除3条讨论标题，并将同文的协议别名合并；当前数量由 `VERIFICATION.md` 自动生成。

人工统一简称与完整标题：Uni-LaViRA、MTU3D。ABot-AgentOS static memory 的8/24帧属于实验设置，合并入同篇论文。旧ID映射保存在 `data/redirects.json`。不会把只有同名关系的论文强行合并。

- 4D-GS（2310.08528）与原生4DGS（2310.10642）：不同作者与时空表示。
- RoboHarness（2603.24060）与RoboHarness（2607.18060）：分别为冻结策略上下文适应与异构策略编排。
- AgenticNav工具式VLN（2606.10577）与层级MAS系统：不同作者、实现与评测；旧笔记混用的自定义场景和R2R-CE不共用实验条目。
- 多个EQA方法使用不同骨干、题目子集、GT路径/自主导航与judge；这些变体不能当作独立论文或直接可比排名。
